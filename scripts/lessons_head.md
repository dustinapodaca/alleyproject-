# How to use these lessons

Each workday (Monday, Tuesday, Friday, Saturday and Sunday) has one lesson that teaches exactly what that day's Mill Alley task needs. Do it before the Mill Alley task, in this order:

1. **Watch and read first.** Start with the video or article, then keep the Blender Manual page open while you work.
2. **Steps.** Follow them in Blender 5.2 LTS with the menus and shortcuts given. Menu paths are written as *Menu > Submenu > Item*.
3. **Common mistakes.** Read these before the drill; they're the problems you're most likely to hit.
4. **Drill.** Do it from a blank file, timed. It's only done when every point under *Pass when* is true. If it isn't, redo it on the next buffer day.
5. **Use it on Mill Alley.** Then do the day's Mill Alley task with what you just practised.

Wednesdays and Thursdays are off. Buffer days have no new lesson: use them to catch up or redo drills. Tick lessons off in the tracker app, where every lesson also opens in full.
